## Core Services

### 1. Software Troubleshooting

Diagnosis and resolution of difficult engineering problems involving:

- C++ / Qt applications
- CMake and build systems
- MSVC / GCC / Clang compatibility
- Windows DLL and runtime dependency issues
- Linux deployment and service failures
- TCP/IP, MQTT, HTTP, and network communication
- Database integration and runtime issues
- Multithreading, stability, and performance problems

**Typical workflow**

> Reproduce → Analyze → Identify root cause → Propose fix → Validate

### 2. C++ / CMake Engineering Review

Technical review of existing C++ projects, including:

- Project structure and module boundaries

- Cross-platform portability
- Error handling
- Logging and diagnostics
- Threading and concurrency
- Resource and lifetime management
- Testing strategy
- Deployment architecture

**Typical deliverables**

- Technical findings
- Risk classification
- Recommended changes
- Refactoring priorities
- Implementation roadmap

---

### 3. Legacy Software Modernization

Modernization planning and implementation for mature software systems.

**Typical scenarios**

- Legacy Visual Studio projects
- Old C++ / Qt applications
- qmake or custom build systems
- Windows-only applications
- Outdated third-party dependencies
- Systems with limited documentation or automated tests

**Possible modernization paths**

- Legacy build → CMake
- Old compiler → modern toolchain
- Windows-only → cross-platform
- Monolithic code → modular architecture
- Manual deployment → reproducible deployment

> The goal is not to rewrite everything.  
> The goal is to modernize the system while controlling technical and operational risk.
